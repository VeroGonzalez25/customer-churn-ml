# Customer Churn ML - Proyecto Integrador ISTEA

## Descripcion
Proyecto de clasificacion binaria para predecir la perdida de clientes (Customer Churn).

## Estructura
- `data/`: Datasets (gestionados con DVC).
- `src/`: Modulos Python de carga, preprocesamiento y entrenamiento.
- `notebooks/`: Analisis exploratorio de datos (EDA).
